GDB Commands Reference
======================

.. note::
   **Auto by Extension = Yes** means the Renesas Debug extension already sends this command automatically.
   Do not add these commands to ``initCommands`` or ``preRunCommands`` as they will be sent twice,
   which may cause conflicts or unexpected behavior.

+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| Command                                                           | Description                                                                                                                                                                                                    | Auto by Extension |
+===================================================================+================================================================================================================================================================================================================+===================+
| ``-gdb-version``                                                  | Show GDB version information. Equivalent to 'show version'. No options or params required.                                                                                                                     | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-environment-cd <path>``                                        | Change the current working directory of the debugged program. GDB will look for files and libraries in the given path.                                                                                         | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set breakpoint pending <mode>``                            | Control pending breakpoint behavior when a location cannot be resolved. Allowed values — on: create pending breakpoint without confirmation; off: abort with error; auto: ask user (default).                  | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set breakpoint auto-hw <mode>``                            | Control automatic hardware/software breakpoint selection. Allowed values — on: use target memory map to decide (default); off: do not auto-select, warn when setting software breakpoint at read-only address. | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set breakpoint always-inserted <mode>``                    | Control when breakpoints are inserted into target memory. Allowed values — on: insert at all times, remove only when deleted; off: insert only when target resumes, remove when target stops (default).        | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set detach-on-fork <mode>``                                | Control GDB behavior after fork(). Allowed values — on: remain attached to parent or child per follow-fork-mode (default); off: attach to both parent and child.                                               | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set follow-fork-mode <mode>``                              | Choose which process to follow after fork(). Allowed values — parent: debug original process, child runs unimpeded (default); child: debug new process, parent runs unimpeded.                                 | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set python print-stack <mode>``                            | Control Python exception output verbosity. Allowed values — full: print full Python stack; none: disable all Python stack and message printing; message: print only the error message (default).               | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set print object <mode>``                                  | Control object type printing. Allowed values — on: print actual derived type using run-time type identification; off: display only the declared type (default).                                                | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set print sevenbit-strings <mode>``                        | Control string character encoding in output. Allowed values — on: print 8-bit characters as \nnn escape notation; off: print full 8-bit characters (default).                                                  | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set host-charset <charset>``                               | Set the host character encoding. Default is UTF-8. Example: -gdb-set host-charset UTF-8.                                                                                                                       | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set dprintf-style <mode>``                                 | Set the output method for dprintf breakpoints. Allowed values — call: use a function call; gdb: use GDB output; agent: use in-process agent.                                                                   | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set target-async <mode>``                                  | Control GDB execution mode. Allowed values — on: GDB continues executing commands while waiting for target; off: GDB waits for target before continuing.                                                       | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set pagination <mode>``                                    | Control output pagination. Allowed values — on: pause at end of each output page; off: display all output without pausing.                                                                                     | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set non-stop <mode>``                                      | Control thread stop behavior on debug events. Allowed values — on: only the affected thread stops, others continue; off: all threads stop (default).                                                           | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set auto-solib-add <mode>``                                | Control shared library symbol loading. Allowed values — on: auto-load symbols when inferior starts or a new library is mapped; off: load symbols manually.                                                     | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set language <lang>``                                      | Set the language for a thread group. Use auto to infer language from source code. Can be combined with --thread-group <id>.                                                                                    | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set env <name> = <value>``                                 | Set an arbitrary environment variable for the debug session. Example: -gdb-set env MY_VAR = 1.                                                                                                                 | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-gdb-set env SIMTOOLS_TOOLDEBUG_ENABLE = 1``                    | Enable simulation tool debug mode via environment variable.                                                                                                                                                    | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``set step-mode <mode>``                                          | Control stepping into functions with no debug info. Allowed values — on: stop at first instruction; off: step over such functions (default).                                                                   | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``set endian <mode>``                                             | Set the target byte order. Allowed values — big: assume big-endian; little: assume little-endian; auto: use byte order from executable (default).                                                              | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``set breakpoint always-inserted <mode>``                         | Keep breakpoints inserted in target memory at all times. Allowed values — on: always inserted; off: insert only when target resumes (default).                                                                 | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``set confirm <mode>``                                            | Control GDB confirmation prompts. Allowed values — on: prompt for confirmation; off: disable all prompts.                                                                                                      | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``set remotetimeout <seconds>``                                   | Set the timeout to wait for the remote target to respond, in seconds. Example: set remotetimeout 10.                                                                                                           | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``set tcp connect-timeout <seconds>``                             | Set the timeout for establishing a TCP connection to the remote target, in seconds. Use unlimited to wait indefinitely. Example: set tcp connect-timeout 30.                                                   | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``set backtrace limit <n>``                                       | Limit the backtrace depth to n levels. Example: set backtrace limit 11.                                                                                                                                        | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``set arch <architecture>``                                       | Set the target architecture. Example: set arch v850e3v5 (used for RH850 targets).                                                                                                                              | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``source <filename>``                                             | Read and execute GDB commands from the specified file. Example: source setup.gdb.                                                                                                                              | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-enable-pretty-printing``                                       | Enable pretty-printing of complex data structures such as C++ containers or custom types. No options or params required.                                                                                       | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``symbol-file <filename> [-o offset]``                            | Load symbol table from the specified file. Optional -o offset is added to the start address of each section. Calling with no argument clears existing symbol table.                                            | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``exec-file [filename]``                                          | Specify the program to be run. Omitting filename discards information on the executable file.                                                                                                                  | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``restore <filename> binary [offset]``                            | Restore binary data from a file into target memory at an optional memory offset. Example: restore image.bin binary 0x08000000.                                                                                 | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``inferior [number]``                                             | Without number: show information about the current inferior. With number: switch GDB context to the specified inferior process.                                                                                | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-add-inferior [-copies n] [-exec executable] [-no-connection]`` | Add n inferiors to be run using the specified executable. -no-connection starts the new inferior with no connection yet.                                                                                       | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-list-thread-groups [identifier]``                              | List all top-level thread groups (processes) GDB is currently debugging. With identifier: list members of that specific thread group.                                                                          | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-thread-select <id>``                                           | Make the thread with the specified global number the current thread. Prints the new current thread number and its topmost frame. Example: -thread-select 1.                                                    | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-stack-select-frame --thread <n> <frame>``                      | Select a specific stack frame for the given thread to inspect variables or evaluate expressions. Example: -stack-select-frame --thread 1 0.                                                                    | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-file-exec-and-symbols --thread-group <id> <program>``          | Load both the executable file and its symbols for a specific thread group.                                                                                                                                     | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-target-attach-no-stop --thread-group <id> <pid>``              | Attach to a running process without stopping it.                                                                                                                                                               | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-target-detach [thread-group]``                                 | Detach GDB from the target or a specific thread group. Without thread-group: detach from the current target.                                                                                                   | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``target remote <host:port>``                                     | Establish a TCP connection to the remote target. Note: some targets support only target remote, not extended-remote. Example: target remote localhost:61234.                                                   | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``target extended-remote <host:port>``                            | Establish an extended TCP connection to the remote target. Supports additional features such as run and attach. Example: target extended-remote localhost:61234.                                               | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-break-insert -t -h -f <function>``                             | Insert a temporary (-t) hardware (-h) breakpoint at the specified function. -f creates a pending breakpoint if the location cannot be resolved immediately.                                                    | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-break-insert -t -f <function>``                                | Insert a temporary (-t) software breakpoint at the specified function. -f creates a pending breakpoint if the location cannot be resolved immediately.                                                         | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``handle SIG32 pass nostop noprint``                              | Configure GDB signal handling for SIG32: pass the signal to the program without stopping execution or printing a message.                                                                                      | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``info line <source>:<line>``                                     | Query the address range for a specific source file and line number. Example: info line main.c:42.                                                                                                              | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``info line <function>``                                          | Query the memory start address of a function by name. Example: info line hal_entry.                                                                                                                            | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``info line *<address>``                                          | Query source line information for a specific memory address. Used internally by the extension. Example: info line *224.                                                                                        | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``info mem``                                                      | Display the memory map of the target, showing memory regions and their attributes (read/write/execute permissions).                                                                                            | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor is_target_connected``                                   | Check whether the target device is currently connected to the GDB server.                                                                                                                                      | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor set_target,<device>``                                   | Set the target device on the Renesas GDB server. Example: monitor set_target,R7FA4M2AD.                                                                                                                        | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor reset``                                                 | Reset the target device.                                                                                                                                                                                       | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor prg_download_start_on_connect``                         | Initiate the program download (flash programming) sequence when the target connects.                                                                                                                           | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor prg_download_end``                                      | Signal to the GDB server that program download has completed.                                                                                                                                                  | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor enable_stopped_notify_on_connect``                      | Enable stopped-state notification when a connection is established.                                                                                                                                            | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor enable_execute_on_connect``                             | Enable execution of target commands upon connection.                                                                                                                                                           | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor force_rtos_on``                                         | Force RTOS thread awareness on in the GDB server.                                                                                                                                                              | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor force_rtos_off``                                        | Force RTOS thread awareness off in the GDB server.                                                                                                                                                             | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor launch_complete``                                       | Signal that the launch sequence for this debug session is complete.                                                                                                                                            | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor all_launches_complete``                                 | Signal that all sessions in a multi-core launch are complete.                                                                                                                                                  | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor configuration_complete``                                | Signal that target configuration is complete.                                                                                                                                                                  | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor do_nothing``                                            | Send a no-op command to the GDB server.                                                                                                                                                                        | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor start_interface,ADM,<cores>``                           | Start an ADM interface for the specified Cortex cores.                                                                                                                                                         | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor get_interface_port,ADM,<cores>``                        | Retrieve the GDB port for an ADM Cortex interface.                                                                                                                                                             | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor get_synchronised_cores``                                | Query which cores are currently synchronized.                                                                                                                                                                  | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor go_all,<core>``                                         | Resume execution on all cores simultaneously.                                                                                                                                                                  | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor stop_all,<core>``                                       | Pause execution on all cores simultaneously.                                                                                                                                                                   | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor query_breakpoint_availability <address>``               | Query whether a breakpoint at the given address is hardware, software, or unavailable.                                                                                                                         | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``monitor get_interface_port,<type>,<name>``                      | Retrieve the GDB port number for a named interface type.                                                                                                                                                       | Yes               |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-exec-continue [--reverse] [--all | --thread-group <id>]``      | Resume execution of the inferior. --reverse: resume in reverse; --all: resume all inferiors. Equivalent to GDB 'continue'.                                                                                     | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-exec-next [--reverse]``                                        | Resume execution stopping at the next source line, stepping over function calls. --reverse: resume in reverse. Equivalent to GDB 'next'.                                                                       | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-exec-step [--reverse]``                                        | Resume execution stopping at the next source line, stepping into function calls. --reverse: resume in reverse. Equivalent to GDB 'step'.                                                                       | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-exec-finish [--reverse]``                                      | Resume execution until the current function exits and display the return value. --reverse: resume in reverse. Equivalent to GDB 'finish'.                                                                      | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-exec-interrupt [--all | --thread-group <id>]``                 | Interrupt background execution of the target. --all: interrupt all inferiors. Equivalent to GDB 'interrupt'.                                                                                                   | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-exec-run [--all | --thread-group <id>] [--start]``             | Start execution of the inferior from the beginning. --start: stop at the start of main. Equivalent to GDB 'run'.                                                                                               | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-exec-return``                                                  | Make the current function return immediately without executing further. Equivalent to GDB 'return'.                                                                                                            | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-exec-next-instruction [--reverse]``                            | Execute one machine instruction, continuing through function calls. Equivalent to GDB 'nexti'.                                                                                                                 | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-exec-step-instruction [--reverse]``                            | Execute one machine instruction, stepping into function calls. Equivalent to GDB 'stepi'.                                                                                                                      | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
| ``-exec-jump <locspec>``                                          | Resume execution at the address resolved from locspec. Equivalent to GDB 'jump'.                                                                                                                               | No                |
+-------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------+
